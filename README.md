# Sphere screen — купол новостей

Круглый интерфейс для больших круглых терминалов, дисплеев и очков: бесконечное поле новостных карточек, натянутое на полусферу, со стеклянными карточками-линзами.

Открыть: https://spevyakin-web.github.io/sphere-screen/

## Жесты
- Один палец / трекпад — двигать поле, карточка встаёт в центр.
- Щипок (или Ctrl + колесо) — масштаб, можно одновременно с прокруткой двумя пальцами.
- Касание центральной карточки — статья раскрывается в ней же; касание вне кнопок — назад.
- Касание двумя пальцами (или правый клик) — карточка переворачивается: источники и факты.

## Установка
На телефоне: «Поделиться → На экран Домой» (Safari) или «Установить приложение» (Chrome). Работает на весь экран и без интернета.
Для стоек: Chrome в режиме киоска с этой ссылкой.

Файлы: `index.html` (движок на canvas + Preact/htm для статьи), `htm-preact.js`, `manifest.json`, `sw.js`, иконки.
